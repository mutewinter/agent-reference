# Knowledge base

Versioned documentation is the system of record for this project's architecture and
decisions; prefer it over chat history. Keep documents evergreen and safe to share: no
secrets, no machine paths, nothing tied to one person or moment.

| Section | What belongs there | Shape |
| --- | --- | --- |
| [architecture/](architecture/README.md) | How the system works today | Undated topic slugs, corrected in place |
| [decisions/](decisions/README.md) | Why the design is the way it is | One file per decision, `YYYY-MM-DD-short-slug.md`, superseded rather than edited |
| visual-explanations/ | Single-use visuals an agent writes for a human to read now | Gitignored, not history |

Each section's README carries its conventions and an index of its files. The governing
distinction: architecture is corrected, decisions are superseded.
